# 集成战略群友赛 #5 · 赛事页面与算分器

「沉沦者的黑流树海」主题比赛页面，包含赛事说明、比赛规则预留页、7×10 赛程表与逐选手记分计算器。纯静态页面，无构建步骤、无外部依赖，双击 `index.html` 即可使用。

## 文件说明

```text
index.html              页面结构（四个子页面）
styles.css              全部视觉样式与响应式布局
app.js                  计分逻辑、自动保存、排名、关卡数据
assets/background.jpg   正式背景图
assets/background.svg   旧版背景占位稿（已不再引用）
assets/squads/*.png     PRTS 分队图标（17 个）
assets/favicon.svg      站点图标
```

## 打开方式

直接打开 `index.html` 即可。若浏览器对本地文件限制较多，可在目录中启动一个静态服务器：

```powershell
python -m http.server 8080
```

然后访问 <http://127.0.0.1:8080/>。

## 四个子页面

1. **01 赛事说明**：比赛主题、比赛方式、赛制、奖励。已删除原「1.5 比赛规则文件」栏目。
2. **02 比赛规则**：新增的规则预留页，当前显示空状态，待主办方补充。
3. **03 比赛赛程**：固定 7 列 × 10 行，自动读取算分器中的昵称、日期、难度、分队、六星干员和最终得分，按得分降序排名。
4. **04 记分计算器**：支持 1—10 位选手，每位选手一个独立页面；所有改动自动保存到当前浏览器的 `localStorage`。

## 计分口径

### 第二部分：关卡通关得分

共 60 个关卡，按 5 类、16 个可折叠关卡组呈现：

1. **「险路恶敌」**：6 个关卡中单选，已删除所有【谒日之祈】加分；顺序为铁腕迷思、狂热敬虔、光荣远征、哀悼铁腕、冰冷流亡、赤金厄运。
2. **紧急作战**：III / IV / V / VI 四组，组内可多选。
3. **特殊作战**：结局前置、流窜居民、居民据点、鸭爵团伙；已删除「湖中仙女」栏。结局前置为单选，其余可多选。
4. **非险路恶敌追猎**：I / II 组单选，IV 组可多选。
5. **结局险路恶敌**：4 个结局关卡组均为单选，均支持「未通关得分补偿」。

统一口径：

- 每个关卡勾选后才会展开并计分。关卡卡片显示基础分、无漏分、额外加分项和单选/多选状态。
- 单选组切换关卡时，原关卡的无漏、额外加分、选项会一并清空，避免残留。
- 生命蓝图、黑流地脉、特定实托邦按关卡独立勾选。
- 鸭爵团伙的「普通 / 紧急」、结局前置的通关层数、强制重启的「探测先锋」层数，均使用关卡内下拉选择；探测先锋最高档表述为「5 层」。
- **未通关得分补偿**：按该关的「基础分 + 层数加分 + 已选额外加分」之和的 **40%** 计算；补偿状态下不可再勾选无漏。除【畸症】【熄日】外，追猎、击杀等通关项也不可勾选。
- **补偿特例**：【畸症】【熄日】勾选补偿后，仍可勾选【追猎】和【击杀】，且这两项加分计入 40% 补偿；勾选追猎仍会禁用对应的黑流地脉 / 特定实托邦。
- **追猎互斥**：结局【纠缠，调和】的畸症、结局【旧日重燃】的熄日，勾选「追猎」后会自动清除并禁用【黑流地脉】与【特定实托邦】加分。
- **本轮分值调整**：
  - 险路恶敌：光荣远征生命蓝图 15；哀悼铁腕、赤金厄运生命蓝图 20。
  - 紧急作战：III 全部生命蓝图 15；IV 安魂节起义基础 45、全部生命蓝图 20、取景圣地特定实托邦 15；V 全部生命蓝图 30、全部黑流地脉各减 5；VI 全部生命蓝图 40、贫瘠行军基础 100、黑流地脉 35/40/35/30。
  - IV 追猎：全部生命蓝图 25。
  - 结局关：所有关卡补偿时不可勾选无漏；永无安宁 10/30/25/15，痛苦将息 20/30，维度重构 20/35/25/20，熄日 30/50/30/20（依次为无漏 / 生命蓝图 / 黑流地脉 / 特定实托邦）；畸症为基础 350、无漏 30、黑流地脉 30、特定实托邦 20（无生命蓝图）。
- 关卡组、第二至第五部分、选手总分均实时联动。

### 其他修改口径

- **结局收藏品**：
  - 结局【维度重构】：沙盘α +30、沙盘β +20；两者同时勾选额外 +30。
  - 结局【纠缠，调和】：怦然信标 +40、击坠“神明” +30、湮没“光明” +40、焚毁“文明” +80；后三者同时勾选额外 +60。
  - 结局【旧日重燃】：谒日之祈 +20、祭日之契 +100；可同时勾选。
- **复得之轮 / 果腹**：可同时勾选，分别填写层数 a / b，各扣 `−100×a`、`−150×b`；同时持有时再额外扣 `−100×max{a,b}`。
- **国际探察小队**：抓取同一势力的至少 3 名六星干员后可勾选该势力，每个势力 +50；可勾选多个不同势力，共 19 个势力。
- **沉沦干员**：最多选择 4 名；「未抓取」只能从已选干员中标记，每名 +50。
- **自然物【板藤】**：填写「超量【板藤】失去时价值」，每 1 点价值扣 2 分。
- **【襁褓】**：每个 +15 分。
- **零件箱容量**：`m≤8 +150`、`8<m≤10 +100`、`10<m≤12 +40`、`12<m≤14 +10`、`14<m≤20 0`、`m>20` 每超 1 点 −20。
- **游戏结算**：`结算分÷效率−零件×5−max(收藏品−热水壶−135,0)×5`；效率未填写时该部分按 0 分并显示提示。
- **最终得分**：第二至第五部分之和 × 难度系数 × 分队系数，显示到小数点后两位。
- **排名**：按最终得分降序；同分并列，后续名次按竞赛排名规则顺延。

如需调整关卡数据，编辑 `app.js` 中的 `SCORE_PARTS`；计分入口为 `stageScore()`、`scorePart()`、`scoreOther()`、`scoreSettlement()`。

## 本地数据

- 存储键：`is5-friend-cup-v1`
- 数据仅保存在当前浏览器，不上传服务器。
- 更换浏览器、清理站点数据或无痕模式关闭后，数据不会保留。
- 需要重新开始时，可在浏览器开发者工具中执行 `localStorage.removeItem('is5-friend-cup-v1')` 后刷新。
- 「清空本页」只清空当前选手；其余选手的数据不受影响。
